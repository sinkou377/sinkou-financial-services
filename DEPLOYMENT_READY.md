## 🆘 Common Questions

### Q: Does it cost anything?
**A:** No! GitHub Pages is 100% free. Unlimited storage, bandwidth, and visitors.

### Q: Can I use a custom domain?
**A:** Yes! (Paid) Get a domain from GoDaddy, Namecheap, etc. (~$12/year) and connect it to GitHub Pages.

### Q: How do I get form submissions?
**A:** They go to your email automatically (Formspree). Free tier: 50/month.

### Q: Can I edit the website after uploading?
**A:** Yes! Edit files directly on GitHub or download, edit locally, re-upload.

### Q: How do I add more team members?
**A:** Add photo to `/images/team-members/` and update HTML team section.

### Q: What if I want more gallery images?
**A:** Add images to `/images/gallery/` folder. Website loads them automatically.
